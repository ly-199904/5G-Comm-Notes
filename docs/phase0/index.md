## 为什么先学 Phase 0？

5G NR 协议栈的每一个设计决策，都能在通信原理和无线通信基础中找到"为什么"的答案：

- 为什么 NR 选 LDPC 而不是 Turbo？→ 长码性能略优 + BP 译码天然并行（通信原理 §8.4）
- 为什么 OFDM 子载波间隔必须等于 $1/T_{symbol}$？→ 子载波正交性条件（通信原理 §5，无线通信 §5）
- 为什么 NTN 上行优先 DFT-s-OFDM？→ 高 PAPR 在功率受限链路上不可接受（无线通信 §5.2）
- 为什么 CP 长度与多径时延扩展有关，而与传播时延无关？→ CP 对抗 ISI，TA 对抗传播时延（无线通信 §4.3）

**建议学习顺序**：通信原理 → 无线通信基础 → Phase 1。数字信号处理可在需要时查阅。

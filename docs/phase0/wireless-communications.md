## 一、无线通信概论

### 1.1 为什么无线通信与有线通信如此不同？

有线信道（同轴电缆、光纤）基本是**确定的、时不变的**——工程师知道信号会遇到什么。无线信道是**随机的、时变的**——信号在三维空间中传播，遇到建筑、人体、车辆，产生无数次反射、散射、衍射，每条路径的幅度和相位在毫秒级就可能发生显著变化。

这一根本差异催生了无线通信的全部核心技术：调制选择、信道编码、均衡、分集、MIMO、OFDM……都是在对抗这个**不可控的随机信道**。

### 1.2 频谱资源：无线通信的地基

| 频段 | 代表频率 | 波长 | 主要特性 | 5G 相关 |
|---|---|---|---|---|
| Sub-6GHz (FR1) | 0.7~6 GHz | 5cm~43cm | 覆盖广，穿透强，容量有限 | 5G 主频段 |
| 毫米波 (FR2) | 24.5~52.6 GHz | 6~12mm | 带宽极宽，覆盖近，损耗大 | eMBB 极高速 |
| 太赫兹（研究中）| > 100 GHz | < 3mm | 超宽带，室内短距 | 6G 候选 |

**天线长度约为 $\lambda/4$**：2.4GHz 的 Wi-Fi 天线约 3cm；600MHz 的 4G 基站天线约 12.5cm；28GHz 的 5G 毫米波天线约 2.7mm（可集成数百根）。

### 1.3 5G 三大场景：为什么需要如此不同的技术路径？

```
eMBB（增强移动宽带）：峰值 10Gbps，面向人
  技术路径：宽频谱（毫米波）+ Massive MIMO + 高阶 QAM（256QAM）

mMTC（海量机器连接）：1M 设备/km²，面向物
  技术路径：窄带优先、低功耗、长覆盖（NB-IoT）

URLLC（超可靠低时延）：时延 < 1ms，可靠性 99.9999%
  技术路径：Mini-slot 调度 + 低码率 LDPC + HARQ 快速重传
```

三个场景对有效性（频谱效率）和可靠性（误码率）的要求截然不同，这就是为什么 5G NR 需要灵活的参数集（Numerology）和多种调制编码方案。

## 二、无线电波传播机制

### 2.1 三种基本传播机制

```
直射（LOS，Line of Sight）：
  最理想，没有障碍物遮挡
  卫星通信、空旷地带微波通信
  信号强度随距离平方衰减（d²）

反射（Reflection）：
  电磁波照射到远大于波长的平面（建筑外墙、地面）
  产生镜像路径，与直射波叠加
  可能相长干涉（增强）或相消干涉（衰减）

衍射（Diffraction）：
  电磁波绕过障碍物边缘继续传播
  可以"绕墙角"，提供 NLOS（非视距）覆盖
  频率越低，衍射能力越强（农村低频覆盖的物理基础）

散射（Scattering）：
  照射到粗糙表面或小于波长的物体（树叶、雨滴）
  能量向各方向散射
  城市环境中大量存在
```

### 2.2 路径损耗模型

**自由空间（Friis 定律，仅直射路径）**：

$$\boxed{P_r = P_t G_t G_r \left(\frac{\lambda}{4\pi d}\right)^2}$$

自由空间路径损耗（dB）：

$$PL_{fs}(dB) = 20\log_{10}(d) + 20\log_{10}(f) + 20\log_{10}\!\left(\frac{4\pi}{c}\right)$$

距离加倍 → 路径损耗增加 6dB；频率加倍 → 路径损耗增加 6dB。

**这就是为什么 5G 毫米波（28GHz）比 4G（2GHz）的路径损耗高约 23dB（$20\log(28/2)$）——覆盖距离大幅缩短，需要密集基站。**

**双径模型（直射 + 地面反射，$d^{-4}$ 定律）**：

当存在一条直射波和一条地面反射波时，两者相位相消，接收功率按 $d^{-4}$ 衰减（比自由空间快得多）：

$$P_r \propto \frac{h_t^2 h_r^2}{d^4}$$

工程含义：基站天线越高（$h_t$ 大），覆盖越远。

**对数距离路径损耗模型（实测拟合）**：

$$PL(d) = PL(d_0) + 10n\log_{10}(d/d_0) + X_\sigma$$

$n$ 为路径损耗指数（自由空间 $n=2$，密集城市 $n=3\sim5$），$X_\sigma$ 为对数正态阴影分量（$\sigma \approx 4\sim12$ dB）。

### 2.3 链路预算（Link Budget）

链路预算是无线系统规划的基本工具，用来判断在给定距离/功率下通信是否可行：

$$\text{接收信噪比} = P_t + G_t + G_r - PL - \text{噪声功率} - \text{各种损耗}$$

**衰落余量**：实测接收功率是随时间波动的随机量，链路预算中的接收功率只是均值。若要保证 90% 的时间可以正常通信，需要在均值之上额外留 10~20dB 的**衰落余量（Fade Margin）**。

**NTN 链路预算特殊性**（与 Phase 1 NTN 内容直接相关）：

```
卫星链路 vs 地面链路的差异：
  单程距离：地面 < 10km，LEO ≈ 550km（仰角 90°），GEO = 36000km
  自由空间损耗差异：LEO vs 地面 ≈ 35dB，GEO vs 地面 ≈ 52dB
  上行方向：UE 功率受限（手机最大 26dBm），NTN 上行是"链路最薄弱环节"
  → 这是为什么 NTN 上行优先用 DFT-s-OFDM（低 PAPR）和 π/2-BPSK
```

## 三、窄带无线信道（小尺度衰落）

### 3.1 两种尺度的衰落

```
大尺度衰落（阴影衰落）：
  空间尺度：数十到数百米
  原因：地形地物遮挡（建筑、山丘）
  统计模型：对数正态分布
  变化速度：缓慢（秒级~分钟级）
  对抗手段：增大发射功率、宏分集（不同基站接收同一 UE）

小尺度衰落（多径衰落）：
  空间尺度：半个波长（2.4GHz 时约 6cm！）
  时间尺度：毫秒级
  原因：多条路径叠加，相位随位置变化
  对抗手段：分集、OFDM、MIMO
```

**直觉**：走路时手机信号忽强忽弱，只需移动几厘米，这就是小尺度衰落——两路反射波的相对相位在半个波长的位移内就能从相长变为相消。

### 3.2 小尺度衰落的两种模型

**瑞利衰落（无主导路径，NLOS）**：

当接收信号由大量路径叠加，且无主导分量时（如城市密集区）：

$$\text{同相分量 } I(t) \sim \mathcal{N}(0, \sigma^2), \quad \text{正交分量 } Q(t) \sim \mathcal{N}(0, \sigma^2)$$

$$\text{信号幅度 } r = \sqrt{I^2 + Q^2} \sim \text{瑞利分布}$$

$$f_R(r) = \frac{r}{\sigma^2} e^{-r^2/(2\sigma^2)}, \quad r \geq 0$$

**莱斯衰落（有主导路径，LOS）**：

当存在主导路径（如 LOS 链路，或卫星到地面）时，信号幅度服从莱斯分布，莱斯因子 $K$ 越大，LOS 分量越强：

$$K = \frac{\text{主导分量功率}}{\text{多径散射功率}} \quad (K=0 \text{ 退化为瑞利})$$

**NTN 信道特殊性**：LEO 卫星到地面 UE 通常是强 LOS 分量，莱斯因子可达 $K > 10$ dB，信道接近确定性。这直接影响了 MIMO 在 NTN 中的可用层数（高 $K$ → 信道矩阵低秩 → 多层空间复用受限）。

### 3.3 多普勒效应

当 UE 以速度 $v$ 运动时，接收信号产生多普勒频移：

$$f_d = \frac{v}{c} \cdot f_c \cdot \cos\theta$$

其中 $\theta$ 为运动方向与入射波方向的夹角。

**关键参数——相干时间**：

$$T_c \approx \frac{1}{4f_{d,\max}} = \frac{c}{4 v f_c}$$

相干时间是信道保持基本不变的时间。若在 $T_c$ 内完成一次传输，接收端可以用"单次信道估计"处理整个数据块。

**数值感知**：

| 场景 | 速度 | 多普勒 (3.5GHz) | 相干时间 |
|---|---|---|---|
| 步行 UE | 5 km/h | 16 Hz | 15 ms |
| 行驶车辆 | 120 km/h | 389 Hz | 0.64 ms |
| 高铁 | 350 km/h | 1134 Hz | 0.22 ms |
| LEO 卫星 | 27000 km/h | 87.5 kHz | 2.9 μs |

相干时间对 CSI 上报周期的设计至关重要——CSI 上报周期必须远小于相干时间，否则 CQI 失效（正是 Phase 2 CSI 框架中的信道老化问题）。

## 四、宽带无线信道（频率选择性衰落）

### 4.1 多径时延扩展——理解 OFDM 为何使用 CP 的关键

当发送宽带信号时，不同路径的到达时延不同，造成接收信号在时域展宽：

```
发送：           |████|
                  ↓ 发出

接收：     路径1  |████|           (无时延，直射)
           路径2     |████|        (时延 τ₁，一次反射)
           路径3         |████|    (时延 τ₂，两次反射)
                  ↓ 叠加

合成信号：  |░░████████░░|         (时域展宽！)
```

**时延扩展 $\Delta\tau_m$**：最晚到达路径与最早路径的时延差。

**码间干扰（ISI）**：前一个码元的"拖尾"叠加到下一个码元的抽样时刻，干扰判决。

**相干带宽（Coherence Bandwidth）**：

$$B_c \approx \frac{1}{\Delta\tau_m}$$

相干带宽是信道频率响应基本不变（相关系数 > 0.5）的最大频率间隔。

| 场景 | 典型时延扩展 $\Delta\tau_m$ | 相干带宽 $B_c$ |
|---|---|---|
| 室内（办公室）| 30~100 ns | 2~7 MHz |
| 城市宏蜂窝 | 1~10 μs | 0.1~1 MHz |
| 郊区 | 0.1~1 μs | 1~10 MHz |
| 地面 5G FR1 NR | ≈ 1~3 μs | ≈ 0.3~1 MHz |
| LEO NTN | < 1 μs（LOS 主导）| > 1 MHz |

### 4.2 信道的双重分类框架

根据信号带宽 $W$ 与相干带宽 $B_c$ 的关系，以及码元周期 $T_s$ 与相干时间 $T_c$ 的关系：

```
                         信道时间特性
                   慢变 (T_s < T_c)    快变 (T_s > T_c)
                ┌─────────────────┬─────────────────┐
信道   平坦     │  ① 理想信道     │  ② 时间选择性   │
频率   (W<Bc)   │  最简单情形     │  需要时间分集   │
特性   ─────────┼─────────────────┼─────────────────┤
       选择性   │  ③ 频率选择性   │  ④ 双选信道     │
       (W>Bc)   │  ISI，需要均衡  │  最复杂（高铁） │
                └─────────────────┴─────────────────┘
```

**5G NR 的情形**：5G 信号带宽（20~400MHz）远大于相干带宽（0.1~10MHz），工作在**频率选择性衰落**区域（情形③）。OFDM 把宽带信道变成若干窄带子信道，每个子信道带宽（15kHz~240kHz）远小于 $B_c$，每个子载波经历**平坦衰落**——化情形③为情形①。

### 4.3 理解 OFDM 循环前缀（CP）的物理本质

```
问题：OFDM 子载波间正交性要求在整个码元时间 T_s 内做积分。
      若存在时延扩展 Δτ，后到达的路径会在"下一个码元"开始积分，
      破坏正交性 → 子载波间干扰（ICI）

解决：在每个 OFDM 码元前加入循环前缀（CP）
  CP 长度 > Δτ_m（时延扩展）
  CP 期间的信号是 OFDM 码元末尾的复制
  接收端等到所有多径都"进入正交积分窗口"后再开始积分
  → 实现线性卷积等效为循环卷积
  → 每个子载波上的信道响应变成一个复数乘法（1-tap 均衡！）

代价：CP 占用约 6.7%~25% 的时间开销（NR 中 Normal CP ≈ 7 个符号 × 144 Ts）
```

**NR 的 CP 长度设计**：μ=0（SCS=15kHz）时，CP 约 4.7μs，能应对约 1.4km 的路径差；μ=2（SCS=60kHz）时，CP 约 1.2μs，只能应对 360m——这是高频 FR2 场景下时延扩展较小的体现。

## 五、OFDM：无线宽带通信的基石

### 5.1 OFDM 的核心思想

```
问题：宽带信道存在频率选择性，不同频率的衰落不一样。
      对整个宽带信号做均衡极其复杂。

思路：把一个宽带信道分成 N 个并行的窄带子信道。
      每个窄带子信道带宽 < 相干带宽 → 近似平坦衰落
      每个子载波上只需1个复数系数来均衡 → 极其简单！

代价：需要 N 个并行的发射机和接收机。
解法：用 IFFT/FFT 实现，复杂度从 O(N²) 降到 O(N log N)
```

**数学本质**：

$$s(t) = \text{Re}\left\{\sum_{k=0}^{N-1} X_k \cdot e^{j2\pi f_k t}\right\}, \quad f_k = f_0 + k \cdot \Delta f$$

子载波间隔 $\Delta f = 1/T_s$（$T_s$ 为有效 OFDM 符号时长），确保子载波间正交：

$$\int_0^{T_s} e^{j2\pi f_k t} \cdot e^{-j2\pi f_m t} dt = \begin{cases} T_s, & k=m \\ 0, & k\neq m \end{cases}$$

### 5.2 OFDM 的两大缺点

**1. 高 PAPR（峰均功率比）**

多个子载波相位偶尔对齐，叠加产生极高的峰值：

$$\text{PAPR} = \frac{\max |s(t)|^2}{\text{mean} |s(t)|^2}$$

OFDM 的 PAPR 可达 10~13dB，要求功率放大器工作在高度线性区，效率低。这就是为什么：
- 5G 上行有 **DFT-s-OFDM** 选项（PAPR 降低 4~6dB）
- NTN 场景优先使用 DFT-s-OFDM（卫星链路上行功率受限）
- PUCCH Format 3 支持 π/2-BPSK（PAPR 接近 0dB）

**2. 对频率偏差敏感（子载波间干扰 ICI）**

若接收端本振与发送端有频率偏差 $\epsilon$，子载波正交性被破坏，产生 ICI。

多普勒频移 $f_d$ 等效于频率偏差，FR2 毫米波场景多普勒更显著，这就是 PT-RS（相位跟踪参考信号）存在的原因。

### 5.3 OFDM 在 5G NR 中的参数选择

| SCS (μ) | $\Delta f$ | 符号时长 $T_u$ | CP 时长 | 适用场景 |
|:---:|:---:|:---:|:---:|---|
| 0 | 15 kHz | 66.7 μs | 4.7 μs | FR1 eMBB |
| 1 | 30 kHz | 33.3 μs | 2.3 μs | FR1 主力 |
| 2 | 60 kHz | 16.7 μs | 1.2/4.2 μs | FR1 高速/FR2 |
| 3 | 120 kHz | 8.33 μs | 0.59 μs | FR2 毫米波 |
| 4 | 240 kHz | 4.17 μs | — | FR2 同步信号 |

SCS 越大 → 每个符号越短 → 时延越低（URLLC 用高 SCS）；但 CP 也越短，抗时延扩展能力越弱。

## 六、数字调制回顾：从通信原理到无线系统

### 6.1 无线环境下的调制选择准则

有别于通信原理中的纯 AWGN 分析，无线系统还需考虑：

```
准则 1：频谱效率 C/B 要高
  → 高阶调制（64QAM、256QAM）
  → 但高阶调制要求高 SNR，信道差时要降阶

准则 2：对噪声不敏感（功率效率 S/N 要低）
  → 低阶调制（QPSK）在覆盖边缘更可靠

准则 3：对多普勒和时延扩展鲁棒
  → 基带成型（奈奎斯特脉冲）减少频谱泄漏
  → OFDM 对抗时延扩展

准则 4：便于硬件实现，PAPR 不能太高
  → 恒包络调制（FSK、π/2-BPSK）适合上行受限场景
```

### 6.2 5G NR 使用的调制方案总结

| 信道 | 调制方案 | 最高阶数 | 选择依据 |
|---|---|---|---|
| PDSCH（下行数据）| CP-OFDM | 256QAM | 下行 SNR 高，追求吞吐量 |
| PUSCH（上行数据）| CP-OFDM 或 DFT-s-OFDM | 256QAM / 64QAM | DFT-s 降 PAPR |
| PUCCH（上行控制）| 取决于 Format，QPSK/π/2-BPSK | — | 低 PAPR 优先 |
| PDCCH（下行控制）| QPSK（固定）| QPSK | 鲁棒性优先，不追求高效率 |
| PBCH（广播）| QPSK | QPSK | 最大覆盖 |

**自适应调制编码（AMC）**：5G NR 根据 UE 反馈的 CQI，在 QPSK~256QAM 之间动态调整——这就是 Phase 2 CSI 框架的核心功能。

### 6.3 星座图与信道条件的关系

```
信道条件好（SNR 高）→ 用高阶 QAM：
  ┌──┬──┬──┬──┐
  │  │  │  │  │   每个格子小，点间距近
  ├──┼──┼──┼──┤   需要高 SNR 才能区分
  │  │  │  │  │   但每符号携带 8 bits（256QAM）
  └──┴──┴──┴──┘

信道条件差（SNR 低，覆盖边缘）→ 用低阶 QPSK：
  ┌──┬──┐
  │  │  │   每个格子大，点间距远
  ├──┼──┤   抗噪声强，但每符号只携带 2 bits
  └──┴──┘
```

## 七、信道编码：逼近香农极限之路

### 7.1 为什么需要信道编码？

无线信道即使经过均衡，仍然无法消除误码（差错底基 error floor）。信道编码通过增加可控的冗余，使接收端能够检测并纠正错误。

**费诺不等式的启示**：无论多么精妙的解调方案，在有噪信道中误码率总有下限。信道编码是降低误码率的唯一出路。

### 7.2 编码发展史与 5G 的选择

```
1948  Shannon 提出信道容量极限
  ↓
1955  汉明码（分组码，简单但性能差）
  ↓
1967  维特比算法（卷积码高效译码）
  ↓
1993  Turbo 码：距 Shannon 限仅 0.5dB（4G LTE 数据信道采用）
  ↓
1996  LDPC 码：逼近 Shannon 限，译码可并行（5G NR 数据信道采用）
  ↓
2008  Polar 码：信息论最优，低短码性能差（5G NR 控制信道采用）
```

**5G NR 的编码选择**（38.212）：

| 信道 | 编码方案 | 理由 |
|---|---|---|
| PDSCH / PUSCH | **LDPC** | 高码率下性能最优，译码可并行，适合大块数据 |
| PDCCH / PUCCH / PBCH | **Polar** | 短块性能优，适合小块控制信息 |

### 7.3 LDPC 码的工程直觉

LDPC = Low Density Parity Check（低密度奇偶校验码）

**校验矩阵稀疏**：每行/列只有少量非零元素，使得消息传递（置信传播 BP）译码算法高效可行。

```
编码：通过稀疏的生成矩阵 G 将 k 个信息比特编成 n 个码字
  编码效率（码率）R = k/n

译码（BP 算法）：
  - 在 Tanner 图上迭代传递"置信度消息"
  - 每个校验节点验证其连接变量节点的奇偶性
  - 迭代收敛 → 输出比特判决
  - 算法天然适合并行实现 → 译码时延低

5G NR 中 LDPC 有两个基础图（Base Graph）：
  BG1：适合大 TB（Transport Block）+ 高码率（eMBB 高吞吐）
  BG2：适合小 TB + 低码率（URLLC、边缘覆盖）
```

### 7.4 最小码距与纠错能力

无论哪种编码，其纠错能力由**最小码距** $d_{min}$ 决定：

| 能力 | 最小码距要求 |
|---|---|
| 检测 $e$ 个错码 | $d_{min} \geq e+1$ |
| 纠正 $t$ 个错码 | $d_{min} \geq 2t+1$ |
| 纠正 $t$ 个同时检测 $e$ 个 | $d_{min} \geq t+e+1$，且 $e>t$ |

5G NR 的 HARQ-IR（增量冗余）本质上是通过多次传输不同的冗余版本（RV0/2/3/1），逐渐增大等效码距，实现软合并增益。

## 八、均衡：对抗 ISI 的工具

### 8.1 均衡的必要性

OFDM 通过 CP 基本消除了 ISI，每个子载波上只需**1-tap 频域均衡**：

$$\hat{X}_k = \frac{Y_k}{H_k}$$

这极大地简化了均衡问题。但信道系数 $H_k$ 需要通过**参考信号（DMRS）**估计。

单载波（DFT-s-OFDM）仍需更复杂的均衡：

**ZF（迫零）均衡**：完全消除 ISI，但在深衰落频率处会放大噪声（噪声增强）。

**MMSE 均衡**：在消除 ISI 和防止噪声放大之间取折中，最小化均方误差：

$$\mathbf{W}_{MMSE} = \mathbf{H}^H(\mathbf{H}\mathbf{H}^H + \frac{1}{SNR}\mathbf{I})^{-1}$$

MMSE 是 5G NR PDSCH 接收机的标准配置，也是 MIMO 检测器的基础（Phase 2 MIMO 课程中的 MMSE 检测器正是同一公式）。

### 8.2 自适应均衡与信道估计

无线信道时变，均衡系数需要实时更新：

```
方法 1：训练序列（导频）
  - 发送已知序列，接收端估计信道
  - 5G NR 中的 DMRS（解调参考信号）就是导频
  - 开销 ≈ 4%~25%（取决于 DMRS 密度配置）

方法 2：决策反馈
  - 利用已判决的数据符号更新信道估计
  - 减少导频开销，但错误传播风险

DMRS 频域插值：
  DMRS 只占部分子载波，其余通过插值估计
  Type 1: 交替子载波 → 最多 4 端口
  Type 2: CDM 组 → 最多 8 端口（频率资源消耗更多）
```

## 九、分集：对抗衰落的根本手段

### 9.1 分集的本质

**单天线系统的困境**：单条路径经历深衰落（信号极弱），误码率飙升，无论怎么提高 SNR，平均误码率下降极慢（随 $1/\text{SNR}$ 下降，而非指数下降）。

**分集的原理**：使用多条**统计独立**（或高度不相关）的信道路径。各路径同时经历深衰落的概率远小于单路径深衰落的概率：

$$P(\text{所有 }N\text{ 路都深衰落}) = P(\text{单路深衰落})^N$$

分集阶数 $N$ 越大，曲线在误码率-SNR 图上的斜率越陡（衰落指数从 $1/\text{SNR}$ 变为 $1/\text{SNR}^N$）。

### 9.2 分集的分类与 5G 的实现

**空间分集（最重要）**：

```
接收分集：多根接收天线
  - MRC（最大比合并）：各路加权后相加，加权系数为信道共轭
  - 5G NR UE 通常有 2~4 根接收天线
  - 分集增益 = 天线数

发射分集：多根发射天线
  - SFBC（空频块码）：PBCH 默认使用，无需 CSI 反馈
  - 预编码 + 分集：PDSCH 可配置
```

**频率分集**：

```
天然频率分集：OFDM 系统中，不同子载波经历不同衰落
  信道编码 + 交织 → 将一个码字分散到多个不同衰落的子载波上
  → 虽然部分子载波深衰落，但整体码字仍可恢复

OFDM 频率分集 = 信道编码与频率选择性衰落的结合！
这是 LDPC + OFDM 组合的核心优势。
```

**时间分集**：

```
信道编码 + 时间交织：
  将数据分散到多个不同时刻（间隔 > 相干时间）
  HARQ 重传就是时间分集！
  重传发生在不同时刻，信道可能已经改变（不再深衰落）
```

**MIMO 空间复用 vs 空间分集的权衡**：

```
空间分集（Spatial Diversity）：
  多天线用于对抗衰落，提高可靠性
  RI = 1（单层）
  适合：信道差、覆盖边缘

空间复用（Spatial Multiplexing）：
  多天线用于并行传输多路数据流，提高吞吐量
  RI > 1（多层）
  适合：信道好、LOS 路径少（多散射路径 → 信道矩阵满秩）

5G NR 自适应选择（Phase 2 RI 上报）：
  UE 测量信道 → 估计最优层数（RI）→ 上报给 gNB
  gNB 根据 RI 决定用空间复用还是分集
```

## 十、扩频通信与多址接入

### 10.1 直接序列扩频（DS-SS）

用速率远高于数据速率的伪随机序列（扩频码）对信号进行调制，将窄带信号展宽到宽带：

$$\text{处理增益} = \frac{B_{RF}}{B_{info}} = \frac{R_{chip}}{R_b}$$

**优点**：抗多径（RAKE 接收机利用多径增益）、抗窄带干扰、低截获概率（信号功率谱密度低于热噪声）。

**CDMA 的代价——远近效应**：

```
靠近基站的 UE 信号强 → 掩盖远处 UE 的弱信号
解决：精确的功率控制（WCDMA 每1ms调整一次功率）
5G NR 废弃了 CDMA，但功率控制仍然保留用于 PUSCH/PUCCH
```

**4G LTE/5G NR 为何放弃 CDMA？**：OFDM + MIMO 在频谱效率上远超 CDMA，且 OFDM 通过 CP 已解决多径问题，CDMA 的多径优势不再突出。

### 10.2 多址接入方案对比

| 技术 | 多址维度 | 代表系统 | 对 5G NR 的影响 |
|---|---|---|---|
| FDMA | 频率 | 1G 模拟 | FDM 仍用于载波聚合（CA）|
| TDMA | 时间 | GSM (2G) | 时分仍用于 TDD 帧结构 |
| CDMA | 码字 | WCDMA (3G) | 扩频码仍用于 NR 中 PRACH（ZC 序列）|
| OFDMA | 频率+时间 RE | LTE (4G) / NR (5G) | 5G NR 的基础多址方案 |

5G NR 本质上是 **OFDMA**：将频时资源网格（Resource Grid）的 RE 分配给不同用户——这正是 Phase 1 Resource Grid 课程的核心内容。

## 十一、5G NR 视角下的知识串联

### 11.1 从本课到 5G NR：每个知识点的落脚

```
本课知识点              5G NR 具体体现
─────────────────────────────────────────────────────
多径衰落模型      →   HARQ 重传（瑞利衰落 → 需要 ACK/NACK）
相干带宽          →   OFDM 子载波带宽（15~240kHz << B_c）
时延扩展          →   CP 长度（Normal CP 4.7μs @ 15kHz）
相干时间          →   CSI 上报周期（需 << T_c）
多普勒频移        →   PT-RS（FR2 相位噪声跟踪）
OFDM + CP         →   5G NR 帧结构 / 资源网格
LDPC              →   PDSCH/PUSCH 编码（38.212 §5.3）
Polar 码          →   PDCCH/PUCCH/PBCH 编码（38.212 §5.4）
MMSE 均衡         →   PDSCH 接收机 / MIMO 检测器
空间分集          →   发射分集 / SFBC
空间复用          →   多层 MIMO（RI > 1）
分集接收          →   UE 多天线合并（MRC）
信道估计          →   DMRS 导频 / 信道估计插值
AMC               →   CQI → MCS 闭环（CSI 框架核心）
功率控制          →   PUSCH 上行功率控制（37.213）
```

### 11.2 一个完整的数据传输流程（串联所有知识点）

```
1. 信道测量（CSI 框架）
   gNB 发送 CSI-RS → UE 估计信道 H
   UE 计算 CQI（信道质量）、RI（最优层数）、PMI（预编码矩阵）
   UE 通过 PUCCH 上报给 gNB

2. 调度决策（gNB）
   根据 CQI 选择 MCS（QPSK~256QAM）
   根据 RI 决定传输层数（空间复用 or 分集）
   发送 DCI（通过 PDCCH）通知 UE 调度结果

3. 数据传输（PHY 层）
   Transport Block → LDPC 编码 → 速率匹配 → 加扰 → QAM 调制
   → 层映射 → 预编码 W → OFDM 调制（IFFT + CP）→ 发射

4. 接收处理（UE 侧）
   CP 去除 → FFT → 频域 MMSE 均衡（利用 DMRS 估计的 H）
   → MIMO 检测 → QAM 解调 → 解码（LDPC）→ CRC 校验

5. 反馈与重传（HARQ）
   CRC 通过 → ACK → 数据成功交付
   CRC 失败 → NACK → gNB 重传（IR 软合并，利用时间分集）
```

## 🔍 常见误区辨析

**Q：OFDM 彻底解决了多径问题吗？**

不完全是。OFDM + CP 消除了 ISI 和 ICI，把每个子载波上的信道变成 1-tap 乘法，但子载波上的幅度衰落（平坦衰落）仍然存在。OFDM 需要配合**信道编码 + 交织**（利用频率分集）和**信道估计 + 均衡**才能完整对抗多径。

**Q：LDPC 和 Turbo 码哪个更好？**

对于 5G NR 应用场景（长码 + 高吞吐）：长 LDPC 性能略优于 Turbo，且 LDPC 的 BP 译码天然并行，时延低，更适合高速传输。NR 选 LDPC 的另一个原因是算法专利问题（Turbo 码专利集中在爱立信）。但在短码场景（控制信道），Polar 码比 LDPC 更优。

**Q：分集增益和编码增益有什么区别？**

分集增益影响误码率曲线的**斜率**（在高 SNR 时曲线变陡，分集阶数越高越陡）；编码增益影响误码率曲线的**水平位移**（等效于信噪比的提升）。两者都是对抗衰落的手段，但机制不同。MIMO 同时利用两者：空间分集提高斜率，空间复用提高编码增益。
